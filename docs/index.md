> Teach Data Engineers How to Think AI.

一部开源技术书籍，帮助具有数据研发背景的工程师完成 AI 思维升级。

本书不是 AI 入门教程，不是 Prompt Engineering 教程，不是框架使用手册。

本书唯一目标：让读者从数据视角理解 AI。

---

## 全书主线

```mermaid
flowchart LR
    A[传统数据平台] --> B[AI Ready Data Platform]
    B --> C[Ontology]
    C --> D[Semantic Layer]
    D --> E[Knowledge Foundation]
    E --> F[RAG]
    F --> G[AI Agent]
    G --> H[Data Loop]
    H --> I[Ontology Evolution]
    I -.循环.-> C
```

整本书只有两个真正的核心：**Ontology** 与 **Data Loop**。

在「驯服业务语义不可靠」与「交付升级版数据产品」两条主线下阅读全书——前者是问题，后者是工程落点（详见[前言](preface/index.md)）。
